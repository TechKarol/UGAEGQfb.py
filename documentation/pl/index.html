Witaj w dokumentacji UGAEGQfb.py

UGAEGQfb.py to lokalny program napisany w Pythonie, służący do szyfrowania i odszyfrowywania tekstu.

Projekt został stworzony jako projekt edukacyjny do nauki języka Python, algorytmów oraz podstaw kryptografii.

Otwórz dokumentację Repozytorium GitHub

O projekcie

Program działa lokalnie w terminalu i nie wymaga połączenia z serwerem do wykonywania szyfrowania.

Aktualna wersja wykorzystuje szyfr Cezara.

Program posiada obsługę dwóch języków:

  • 🇵🇱 Polski
  • 🇬🇧 English

Przykład działania

Przykład szyfrowania tekstu przy użyciu klucza 8: 

Tekst:       Aluta
Klucz:       8
Zaszyfrowano: Itcbi

Do odszyfrowania potrzebny jest ten sam klucz.
