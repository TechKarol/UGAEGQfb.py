1. Opis projektu

UGAEGQfb.py to lokalne narzędzie działające w terminalu, napisane w języku Python.

Program pozwala szyfrować oraz odszyfrowywać tekst przy użyciu prostego szyfru Cezara.

Cel projektu: Nauka języka Python, podstaw algorytmów, funkcji, pętli, obsługi tekstu oraz podstaw kryptografii.

Program nie potrzebuje serwera ani połączenia internetowego do wykonywania operacji szyfrowania.

2. Wymagania

Do uruchomienia kodu źródłowego potrzebujesz:

  • Python 3.x
  • terminala / wiersza poleceń
  • pliku UGAEGQfb.py

Aktualna wersja programu korzysta wyłącznie ze standardowej biblioteki Pythona.

Używany moduł: 

import random

3. Instalacja

Pobierz repozytorium projektu: 

git clone https://github.com/TechKarol/UGAEGQfb.py.git

cd UGAEGQfb.py

5. Algorytm szyfru Cezara

Program wykorzystuje szyfr Cezara. Jest to jeden z klasycznych algorytmów szyfrowania podstawieniowego.

Każda litera zostaje przesunięta w alfabecie o określoną liczbę pozycji.

Przykład dla klucza 3:

A → D
B → E
C → F
D → G
E → H

W programie zastosowano działanie modulo 26: 

E(x) = (x + k) mod 26

Odszyfrowywanie wykorzystuje odwrotne przesunięcie: 

D(x) = (x - k) mod 26

Gdzie:

  • x — pozycja litery
  • k — klucz
  • 26 — liczba liter alfabetu

6. Kod programu

Główna funkcja szyfrująca wygląda następująco: 

def szyfruj(tekst, klucz):
    return ''.join(
        chr((ord(c) - 65 + klucz) % 26 + 65)
        if c.isupper()
        else chr((ord(c) - 97 + klucz) % 26 + 97)
        if c.islower()
        else c
        for c in tekst
    )

Funkcja wykorzystuje:

  • ord() — zamienia znak na liczbę
  • chr() — zamienia liczbę na znak
  • isupper() — sprawdza wielką literę
  • islower() — sprawdza małą literę
  • join() — łączy znaki w tekst
  • % 26 — zapewnia zawijanie alfabetu

Odszyfrowywanie

Funkcja odszyfrowująca wykorzystuje funkcję szyfrującą z ujemnym kluczem: 

def odszyfruj(tekst, klucz):
    return szyfruj(tekst, -klucz)
Dzięki temu nie trzeba pisać drugi raz całego algorytmu szyfrowania.

8. Klucz szyfrowania

Podczas szyfrowania program losuje klucz z zakresu od 1 do 25. 

klucz = random.randint(1, 25)

Klucz jest wyświetlany użytkownikowi razem z zaszyfrowanym tekstem.

Ważne: Klucz jest potrzebny do odszyfrowania wiadomości. Jeśli użytkownik go zgubi, program nie będzie wiedział, jakie przesunięcie zastosować.

9. Bezpieczeństwo

UWAGA: UGAEGQfb.py nie jest obecnie bezpiecznym narzędziem kryptograficznym.

Szyfr Cezara posiada tylko 25 możliwych kluczy. Oznacza to, że osoba atakująca może bardzo łatwo sprawdzić wszystkie możliwe przesunięcia.

Dlatego obecna wersja projektu jest przeznaczona wyłącznie do nauki i eksperymentowania.

Nie należy używać jej do zabezpieczania:

  • haseł
  • danych osobowych
  • kluczy API
  • poufnych wiadomości
  • ważnych plików

10. Budowanie pliku EXE

Program można spakować do pliku wykonywalnego dla systemu Windows za pomocą PyInstaller.

Instalacja:

pip install pyinstaller

Budowanie:

py -m PyInstaller --onefile UGAEGQfb.py

Gotowy plik znajdzie się w katalogu: 

dist/UGAEGQfb.exe
Program korzysta z terminala poprzez input() i print(), dlatego nie należy używać --noconsole.
