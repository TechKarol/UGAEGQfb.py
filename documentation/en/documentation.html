1. Overview

UGAEGQfb.py is a local command-line text encryption program written in Python.

The main purpose of this project is educational. It demonstrates basic programming concepts together with a simple classical encryption algorithm.

The program currently uses the Caesar cipher.

2. Requirements

To run the source code, you need:

  • Python 3.x
  • A terminal / command prompt
  • The UGAEGQfb.py source file

No external Python libraries are required by the current source code.

3. Installation

Download or clone the repository from GitHub. 

git clone https://github.com/TechKarol/UGAEGQfb.py.git

Enter the project directory: 

cd UGAEGQfb.py

Then run the Python program: 

python UGAEGQfb.py

4. Usage

After starting the program, the main menu is displayed: 

1. Encrypt
2. Decrypt
3. Exit

Select an option by entering its number.

Encryption

Select 1, enter your text and the program generates a random Caesar cipher key. 

Enter text to encrypt: Aluta

Encrypted: Itcbi
Key: 8

Decryption

Select 2, enter the encrypted text and provide the key. 

Enter encrypted text: Itcbi
Enter key: 8

Decrypted: Aluta

5. Algorithm

UGAEGQfb.py currently uses the Caesar cipher.

The Caesar cipher shifts letters by a fixed number of positions in the alphabet.

For example, with a key of 3:

A → D
B → E
C → F
D → G

The mathematical operation used by the program is: 

E(x) = (x + k) mod 26

Decryption uses:

D(x) = (x - k) mod 26

Where x is the letter position and k is the encryption key.

6. Code

The main encryption function is: 

def szyfruj(tekst, klucz):
    return ''.join(
        chr((ord(c) - 65 + klucz) % 26 + 65)
        if c.isupper()
        else chr((ord(c) - 97 + klucz) % 26 + 97)
        if c.islower()
        else c
        for c in tekst
    )

The decryption function reuses the encryption function with a negative key: 

def odszyfruj(tekst, klucz):
    return szyfruj(tekst, -klucz)

This avoids duplicating the encryption algorithm.

7. Encryption Key

The current program generates a random key between 1 and 25. 

klucz = random.randint(1, 25)

The key is displayed after encryption.

Important: The key is required to decrypt the message. If the key is lost, the encrypted message cannot be normally decrypted using the program.

8. Security

The current implementation should not be considered secure cryptography.

The Caesar cipher has a very small key space and can be broken easily by trying all possible shifts.

This project is intended for learning and experimentation, not for protecting passwords, personal information or other sensitive data.

Do not use UGAEGQfb.py to protect real sensitive data.

9. Building the EXE

The Python program can be converted into a Windows executable using PyInstaller.

Install PyInstaller:

pip install pyinstaller

Build the executable:

py -m PyInstaller --onefile UGAEGQfb.py

The resulting executable will be located in: 

dist/UGAEGQfb.exe

Because the application uses terminal input and output, it should not be built with --noconsole.
