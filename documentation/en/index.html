Welcome

UGAEGQfb.py is a local text encryption project written in Python.

The project was created as an educational experiment focused on Python programming, algorithms and basic cryptography concepts.

View Documentation GitHub Repository

About the Project

UGAEGQfb.py currently uses a modified implementation of the Caesar cipher for educational purposes.

The program runs locally in the terminal and does not require an online server. 

Text → Encryption → Encrypted Text
Encrypted Text + Key → Decryption → Original Text

Example

Example using the key 8:

Original:   Aluta
Key:        8
Encrypted:  Itcbi

The same key can be used to decrypt the text.

Security Notice

Important: UGAEGQfb.py is an educational cryptography project. The current Caesar cipher implementation is not considered secure for protecting sensitive information.
