UGAEGQfb

UGAEGQfb is a local command-line text encryption project written in Python.

The project was created to learn Python programming, algorithms, cryptography concepts and software development.

About the project

UGAEGQfb currently uses the Caesar cipher as an educational encryption algorithm.

The application runs locally and does not require a server, database or internet connection.
