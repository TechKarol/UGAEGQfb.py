Developer Documentation

Welcome to the UGAEGQfb developer documentation.

UGAEGQfb is a local command-line text encryption application written in Python. The project is mainly intended for learning Python programming, algorithms, basic cryptography and software development.

Project type: Educational CLI application
Language: Python
Encryption: Caesar cipher
Platform: Windows / Python-compatible systems
Network: Not required

1. Requirements

To run the project from source, you need Python 3.x. 

python --version

On Windows you can also use: 

py --version

2. Installation

Clone the repository: 

git clone https://github.com/TechKarol/UGAEGQfb.py.git

Enter the project directory: 

cd UGAEGQfb.py

Run the application: 

python UGAEGQfb.py

Windows users can also run: 

py UGAEGQfb.py

3. Usage

After starting the program, the main menu is displayed: 

1. Szyfruj
2. Odszyfruj
3. Wyjdź

Encrypt

Selecting option 1 starts the encryption process. 

Wpisz tekst do zaszyfrowania:

The program generates a random key between 1 and 25. The encrypted text and key are then displayed. 

Zaszyfrowano: Itcbi
Klucz: 8

Decrypt

Selecting option 2 asks for the encrypted text and the key. 

Wpisz zaszyfrowany tekst:
Podaj klucz:

The application applies the inverse Caesar shift and returns the original text.

4. Encryption Algorithm

UGAEGQfb currently implements the Caesar cipher. The algorithm shifts alphabetic characters by a specified number of positions.

Example: Key = 3 
A → D
B → E
C → F
D → G

X → A
Y → B
Z → C

The mathematical representation of the encryption operation is: 

E(x) = (x + k) mod 26

Decryption uses the inverse operation: 

D(x) = (x - k) mod 26

Because the operation is reversible, applying the inverse key restores the original text.

5. Character Handling

Alphabetic characters are shifted while other characters are preserved.

Character Encrypted?
A-Z Yes
a-z Yes
Numbers No
Spaces No
Punctuation No

Python's ord() and chr() functions are used to convert characters to numerical values and back.

6. Core Code

The main encryption function is: 

def szyfruj(tekst, klucz):
    return ''.join(
        chr((ord(c) - 65 + klucz) % 26 + 65)
        if c.isupper()
        else chr((ord(c) - 97 + klucz) % 26 + 97)
        if c.islower()
        else c
        for c in tekst
    )

The function processes every character in the input string and applies the Caesar transformation only to alphabetic characters.

Decryption function

def odszyfruj(tekst, klucz):
    return szyfruj(tekst, -klucz)

Instead of duplicating the encryption algorithm, decryption simply uses the negative value of the key.

7. Encryption Key

During encryption, a random key is generated: 

klucz = random.randint(1, 25)

This produces an integer in the range: 

1 ... 25

The key is necessary for decryption. If the wrong key is supplied, the original plaintext will not be recovered.

Important:
The current implementation does not save the encryption key to persistent storage. The user must save or remember the key if they want to decrypt the ciphertext later.

8. Security

⚠ IMPORTANT SECURITY WARNING

UGAEGQfb is NOT a secure cryptographic application.

The Caesar cipher is extremely easy to break because there are only 25 possible non-zero shifts.

An attacker can simply test every possible key and determine which result produces readable text.

The project should therefore only be used for education, experimentation and learning.

Do not use the current implementation for:

  • Passwords
  • API keys
  • Private keys
  • Financial information
  • Confidential documents
  • Production secrets
  • Real security systems

9. Building the Windows EXE

The Python application can be packaged into a standalone Windows executable using PyInstaller.

Install PyInstaller: 

pip install pyinstaller

Build the executable: 

py -m PyInstaller --onefile UGAEGQfb.py

The generated executable will appear in: 

dist/
└── UGAEGQfb.exe

The application is a console program, so a console window is required for input() and print().

12. Testing

A basic property of the encryption system is that decrypting encrypted text with the same key should restore the original text. 

decrypt(encrypt(text, key), key) == text

Example: 

Plaintext:
Aluta

Key:
8

Encrypted:
Itcbi

Decrypted:
Aluta
